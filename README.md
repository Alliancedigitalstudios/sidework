# Side Work: Tips & Budget

Income-first budgeting for tipped workers. Log a shift in 10 seconds, see what you actually walked with, match it to your pay card, and budget on the floor, not the average.

- `apps/mobile` — Expo (React Native) app, iOS first
- `packages/engine` — pure TypeScript domain logic + tests
- `backend/supabase` — opt-in backend for Plaid only (RLS, Edge Functions)
- `docs/` — spec, security plan, design brief, build plan

```bash
npm install
npm test
```
