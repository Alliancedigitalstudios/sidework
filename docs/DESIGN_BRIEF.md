# Design Brief (snapshot) — full with 6 Claude Design prompts: https://claude.ai/artifact/6TSz3KaY3qx1qjbAdN1EVR

**Direction:** calm, native, one number per screen (Copilot Money as reference). Income-first, not spend-first. Dark mode first. SF Pro / SF Pro Rounded hero numbers, tabular figures. Teal-green income accent, amber for floor/caution, red only for mismatches. Role chips: Server, Runner, Bartender, Busser, Host. 22pt cards, 44pt targets, 4.5:1 contrast, haptics on save/match/mismatch.

**IA:** tabs Home · Shifts · Money · Insights + floating Log. Settings from Home avatar.

**Screens (14):** onboarding roles / tip-out / money flow / bills+floor; Home; Log shift (server, runner, bartender variants); Shift detail; Shifts calendar; Money buckets; Deposits+reconcile; Paycheck explainer; Bills calendar; Insights; Link bank + Settings.

**Flows + targets:** onboarding <3 min; log shift <15 s; reconcile <10 s; plan a week <60 s; payday <20 s; link bank <90 s; "beat the floor" weekly card.

**Copy tone:** plain, short, never scolding. "Tuesday's $86 hasn't landed yet."
